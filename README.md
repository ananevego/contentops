# ContentOps

ContentOps - Система автоматиации поиска трендов и подготовки контента

## Goals

Система должна:

- собирать контент из внешних источников и сохранять его
- определять потенциальные тренды
- генерировать идеи
- создавать черновики публикация
- предоставлять управление через Telegram бота
